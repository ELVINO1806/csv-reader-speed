A drop-in faster solve.js for the house csv-reader 1.0.0 driver: byte-identical answers on every case, several times faster than the baseline. The driver main.ts is the house entry, unchanged; solve.js is the work.

## Run

The harness runs `node main.ts` with MAKEFUN_INPUT_DIR and MAKEFUN_OUTPUT_DIR set.
